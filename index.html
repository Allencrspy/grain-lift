GrainLift

Load a photo of any mark or surface, box the part you like, and get a Procreate brush with that grain and tip. The shape and grain are built from your pixels. Spacing, jitter and depth are set from how rough, dense and directional the texture is.

1 Select a texture

Sample: generated charcoal on cold-press paper. Drag on the image to select, drag inside the box to move it, drag its corner to resize. You can also drop an image here.

4 Export

On an iPad, Save .brush opens the share sheet: choose Procreate and the brush lands in an Imported set. If Procreate isn't listed, choose Save to Files, then tap the file in Files. On a computer the file downloads, and you can AirDrop it to your iPad. If an import ever fails, make any brush in Procreate, open Brush Studio, and use Shape → Edit → Import and Grain → Edit → Import with the two PNGs. They are the same images the .brush file contains. Texture.png is your selection before tiling, if you'd rather let Procreate's Auto Repeat make the grain seamless.
